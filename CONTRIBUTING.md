# Contribuindo para CONTEC Ibitinga

Obrigado pelo seu interesse em contribuir com o projeto CONTEC!

## Reportando Bugs

Se você encontrou um bug, por favor, crie uma issue no GitHub detalhando:
- Como reproduzir o problema
- Qual era o comportamento esperado
- Capturas de tela (se aplicável)
- Seu sistema operacional e navegador

## Sugerindo Melhorias

Sinta-se à vontade para sugerir novas features através de uma issue. Descreva qual problema sua feature resolve e como ela deveria funcionar.

## Pull Requests

1. Faça um fork do projeto
2. Crie sua branch para a feature (`git checkout -b feature/MinhaFeature`)
3. Commit suas alterações (`git commit -m 'feat: adicionando MinhaFeature'`)
4. Faça o push para a branch (`git push origin feature/MinhaFeature`)
5. Abra um Pull Request

Garanta que suas alterações não quebram o design (teste no mobile e no desktop) e que você rodou `npm run build` para garantir que o projeto compila.
